# 📝 To-Do List App

[![Live Demo](https://img.shields.io/badge/demo-live-green.svg)](https://marveee3.github.io/To-Do-list/)
[![GitHub Pages](https://img.shields.io/badge/GitHub-Pages-blue.svg)](https://marveee3.github.io/To-Do-list/)
[![License](https://img.shields.io/badge/license-MIT-blue.svg)](https://github.com/Marveee3/To-Do-list)

Простое и удобное веб-приложение для управления задачами с возможностью отслеживания прогресса.

## ✨ Особенности

- ✅ **Добавление задач** - Быстрое добавление новых задач
- 🗑️ **Удаление задач** - Удаление выполненных или ненужных задач
- 📊 **Отслеживание прогресса** - Визуализация выполненных задач
- 🎨 **Чистый интерфейс** - Минималистичный и интуитивно понятный дизайн
- 💾 **Локальное хранение** - Данные сохраняются в браузере

## 🚀 Быстрый старт

### Способ 1: Онлайн демо
**👉 [Запустить демо-версию](https://marveee3.github.io/To-Do-list/)**

### Способ 2: Локальная установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/Marveee3/To-Do-list.git
```

2. Перейдите в директорию проекта:
```bash
cd To-Do-list
```

3. Откройте файл `index.html` в браузере или используйте локальный сервер:
```bash
# Для Python 3
python -m http.server 8000

# Для Node.js с установленным http-server
npx http-server
```

## 📝 Использование

1. **Добавление задачи:**
   - Введите текст задачи в поле ввода
   - Нажмите Enter или кнопку "Добавить"

2. **Отметка задачи как выполненной:**
   - Нажмите на задачу, чтобы отметить её как выполненную

3. **Удаление задачи:**
   - Нажмите на кнопку удаления (🗑️) рядом с задачей

4. **Очистка всех задач:**
   - Используйте кнопку "Очистить все" для удаления всех задач

## 🎯 Функциональность

### Основные функции:
- Добавление новых задач
- Отметка задач как выполненных
- Удаление отдельных задач
- Очистка всех задач
- Автоматическое сохранение в LocalStorage
- Подсчёт выполненных задач
